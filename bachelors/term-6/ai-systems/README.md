# Системы искусственного интеллекта

Лабораторные работы по дисциплине «Системы искусственного интеллекта» (6 семестр). Рассмотрены
продукционная, сетевая и фреймовая модели представления знаний, нечёткий вывод, искусственные
нейронные сети и кластеризация.

Отчёты по лабораторным работам 1-2 написаны на Typst. Лабораторные работы 3-11 выполнены в
Jupyter-блокнотах (`lab-N/lab.ipynb`); соответствующий отчёт `lab-N/report.typ` формируется из
блокнота с помощью пакета callisto.

```sh
mise run execute 4         # повторное выполнение блокнота
mise run report-all        # сборка отчётов в директорию reports/
mise run notebook-pdf-all  # экспорт блокнотов в PDF
```
