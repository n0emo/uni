# Квантовая информатика

Лабораторные работы по дисциплине «Квантовая информатика» (3 семестр).

Лабораторная работа 1 выполнена в Jupyter-блокнотах (`lab-1/*.ipynb`): комплексные числа,
преобразование Фурье и тензорное произведение. Лабораторная работа 2 (`lab-2/src`) моделирует
кубиты и квантовые вентили и реализует алгоритм Дойча.

```sh
mise run lab  # запуск JupyterLab
mise run run  # запуск лабораторной работы 2
```
