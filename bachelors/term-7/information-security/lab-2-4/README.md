# Лабораторная работа 2.4

Сервер для обмена зашифрованными сообщениями с электронной подписью. После
подключения к серверу, клиент будет получать сообщения от всех остальных
подключенных клиентов. Сообщения передаются в зашифрованном виде, при этом
сервер имеет доступ к открытым сообщениям.

## Быстрый старт

Запустить сервер:

```console
mise run chat-server 2-4
```

Запустить клиент:

```console
mise run chat-client 2-4
```

Обе задачи принимают адрес вторым аргументом (по умолчанию `127.0.0.1:8080`).
