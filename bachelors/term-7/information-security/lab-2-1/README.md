# Лабораторная работа 2.1

Программа реализует три простейших метода шифрования: замену, перестановку и
гаммирование.

## Быстрый старт

```console
mise run run 2-1 help
mise run run 2-1 replace "ГНЕВ ЭТО КРАТКОВРЕМЕННОЕ БЕЗУМИЕ" 14
mise run run 2-1 permute "ГНЕВ ЭТО КРАТКОВРЕМЕННОЕ БЕЗУМИЕ" 52641730
mise run run 2-1 gamming "ГНЕВ ЭТО КРАТКОВРЕМЕННОЕ БЕЗУМИЕ" "ГОРАЦИИ"
```
