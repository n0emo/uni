# Архитектура вычислительных систем

Лабораторные работы по дисциплине «Архитектура вычислительных систем» (8 семестр). Рассмотрены
метрики параллельной обработки, топологии сетей межсоединений, архитектуры SIMD, конвейерная и
суперскалярная обработка, модели параллельных программ, виртуализация, планирование параллельных
вычислительных процессов, RAID-массивы и оценивание качества ВС.

Лабораторные работы 2-4, 6 и 9 выполнены в Jupyter-блокнотах (`lab-N/lab.ipynb`); соответствующий
отчёт `lab-N/report.typ` формируется из блокнота с помощью пакета callisto. Остальные отчёты
написаны на Typst.

Измерения, которые в сданных работах лежали в таблицах LibreOffice Calc и Excel, вынесены в
`lab-N/data/*.csv`; отчёт строит по ним и таблицы, и графики, так что разойтись они не могут.
Исходные таблицы (`lab-1/calc.ods`, `lab-10/lab.xlsx`) сохранены рядом.

```sh
mise run lab               # запуск JupyterLab
mise run execute 4         # повторное выполнение блокнота
mise run report-all        # сборка отчётов в директорию reports/
mise run notebook-pdf-all  # экспорт блокнотов в PDF
```
