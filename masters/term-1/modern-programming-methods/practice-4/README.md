# Клеточный автомат

Кроссплатформенное графическое приложение для моделирования элементарных
(одномерных) клеточных автоматов Стивена Вольфрама. Программа позволяет:

- наблюдать эволюцию автомата во времени в виде пространственно-временной
  диаграммы;
- выбирать правило и настраивать параметры моделирования;
- задавать начальную конфигурацию клеток.

Программа написана на F# (.NET 10) с использованием библиотеки raylib через
NuGet-пакет [Raylib-cs](https://www.nuget.org/packages/Raylib-cs).

## Модель

Поколение — строка из `N` клеток, каждая из которых либо жива (1), либо мертва
(0). Новое состояние клетки зависит от её окрестности — тройки (левая соседка,
сама клетка, правая соседка), — поэтому возможны 2³ = 8 окрестностей и 2⁸ = 256
правил. Правило задаётся номером от 0 до 255: бит номера с индексом
`4·l + 2·c + r` — новое состояние клетки с окрестностью `(l, c, r)`. Например,
для правила 30:

| Окрестность      | 111 | 110 | 101 | 100 | 011 | 010 | 001 | 000 |
| ---------------- | :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| Новое состояние  |  0  |  0  |  0  |  1  |  1  |  1  |  1  |  0  |

00011110₂ = 30.

У крайних клеток строки не хватает одной соседки. Поддерживаются два вида
граничных условий:

- кольцо (по умолчанию) — первая и последняя клетки считаются соседними;
- нулевые края — за пределами строки клетки всегда мертвы.

Все клетки обновляются одновременно: следующее поколение вычисляется целиком по
предыдущему.

## Окно

Окно делится на две части: слева диаграмма в рамке, справа панель шириной 260
пикселей. Всё, что рисуется на диаграмме, обрезается по её рамке.

Клетка — квадрат 4×4 пикселя. Размер окна можно менять (по умолчанию диаграмма
занимает 800×640 пикселей, а окно не может быть меньше 560×612). Ширина
диаграммы задаёт длину строки (200 клеток по умолчанию), высота — число
поколений на экране (160). При изменении размера окна эволюция начинается заново
с новой длиной строки и одной живой клеткой в центре. Каждое поколение рисуется
строкой под предыдущим, то есть время идёт сверху вниз. Когда диаграмма
заполнена, она прокручивается вверх на одну строку за поколение, и последнее
поколение всегда находится внизу.

Каждым действием можно управлять и с клавиатуры, и кнопками на панели. Панель
разбита на разделы, справа от названия раздела указаны его клавиши:

- «Правило» — номер текущего правила (пока номер набирается с клавиатуры,
  вместо него показывается набранное), кнопки `<` и `>` и таблица переходов:
  восемь окрестностей от 111 до 000, под каждой — новое состояние центральной
  клетки (живое выделено цветом), как на рисунках Вольфрама;
- «Готовые правила» — кнопки правил 30, 90, 110 и 184, кнопка текущего правила
  подсвечена;
- «Воспроизведение» — пауза / продолжение и один шаг; на паузе в углу диаграммы
  выводится надпись PAUSED;
- «Скорость» — текущая скорость и кнопки `-` и `+`;
- «Края» — кнопки граничных условий, текущие подсвечены;
- «Начальное поколение» — одна клетка, случайное или пустое поколение и
  подсказка о редактировании мышью (в низком окне подсказка скрывается, чтобы
  поместилась статистика);
- «Статистика» — номер последнего поколения (первое поколение — нулевое) и
  число и доля живых клеток в нём, то есть в нижней строке диаграммы.

Номер правила, скорость и граничные условия видны в своих разделах панели.

Надписи на панели — на английском, потому что встроенный шрифт raylib не
содержит кириллицы.

По умолчанию начальное поколение — одна живая клетка в центре строки, правило 30,
скорость 20 поколений в секунду.

## Управление

| Клавиша               | Кнопка             | Действие                                                   |
| --------------------- | ------------------ | ---------------------------------------------------------- |
| `0`–`9`, Enter        | —                  | набрать номер правила (0–255) и применить его              |
| Backspace             | —                  | стереть последнюю цифру набранного номера                  |
| ← / →                 | `<` / `>`          | предыдущее / следующее правило (после 255 идёт 0)          |
| F1–F4                 | 30, 90, 110, 184   | готовые правила                                            |
| Space                 | Pause / Play       | пауза / продолжение                                        |
| N                     | Step               | один шаг; если эволюция идёт, она ставится на паузу        |
| `+` / `-`             | `+` / `-`          | скорость: 1, 2, 5, 10, 20, 30, 60 или 120 поколений в секунду |
| B                     | Ring / Zero        | граничные условия: кольцо / нулевые края                   |
| S                     | Single             | одна живая клетка в центре                                 |
| R                     | Random             | случайное начальное поколение (плотность 50 %)             |
| C                     | Clear              | пустое начальное поколение                                 |
| ЛКМ у верха диаграммы | —                  | переключить клетку верхней строки и перезапустить эволюцию |
| —                     | столбец таблицы    | переключить новое состояние окрестности, то есть один бит номера правила |
| Esc                   | —                  | отменить набор номера; если номер не набирается — выход    |

`+` и `-` работают и на основной клавиатуре, и на цифровой; ←, →, `+`, `-` и
Backspace повторяются, если клавишу удерживать.

При смене правила, граничных условий или начального поколения диаграмма
очищается и эволюция начинается заново. При смене правила начальное поколение
сохраняется, так что разные правила можно сравнить на одной и той же строке.

При наборе номера правила цифры, с которыми номер стал бы больше 255, не
принимаются.

Верхняя строка диаграммы — самое старое поколение на экране. Чтобы не целиться
в строку высотой 4 пикселя, щелчок принимается во всей полосе из 8 верхних строк
диаграммы: он переключает клетку верхней строки в том же столбце. Когда курсор
находится над полосой, она подсвечивается, столбец под курсором и клетка
верхней строки выделяются, а курсор принимает вид руки. После щелчка изменённая
строка становится поколением 0. Чтобы нарисовать начальное поколение с нуля,
очистите его клавишей C и щёлкайте по клеткам у верха диаграммы.

## Сборка и запуск

```sh
mise run build  # сборка
mise run run    # запуск
mise run test   # тесты
```

## Тесты

Модель проверяется модульными тестами на Expecto в каталоге `tests/`. Часть
тестов — свойства FsCheck, которые проверяются на сотне случайных
входных данных:

- `applyRule` для всех 256 правил и 8 окрестностей совпадает с битами номера
  правила;
- переход к соседнему правилу замыкается (после 255 идёт 0, перед 0 — 255);
- таблица переходов перечисляет окрестности от 111 до 000, а её новые
  состояния, прочитанные как двоичное число, дают номер правила;
- переключение столбца таблицы меняет новое состояние ровно одной
  окрестности, а повторное возвращает правило;
- разбор номера правила принимает числа от 0 до 255 и отвергает большие числа,
  знаки, пробелы и другие символы;
- правило 90 из одной клетки даёт треугольник Серпинского: строка `t` —
  строка `t` треугольника Паскаля по модулю 2;
- центральный столбец правила 30 совпадает с последовательностью
  [OEIS A051023](https://oeis.org/A051023);
- правило 184 на кольце сохраняет число живых клеток, а при нулевых краях
  клетки «уезжают» за правый край;
- нулевые края дают то же, что кольцо, к которому с обеих сторон добавлено по
  мёртвой клетке;
- число живых клеток и их доля считаются верно;
- пустая строка не содержит живых клеток, а случайная — в среднем заданную долю
  живых клеток (при плотности 0 и 1 — ни одной и все);
- переключение клетки меняет ровно одну клетку, а повторное возвращает строку;
- правила 0 и 255 за один шаг дают пустую и полную строку при любых граничных
  условиях;
- на кольце сдвиг строки и шаг эволюции перестановочны, а длина строки не
  меняется;
- кольцевой буфер истории хранит последние поколения по порядку.
