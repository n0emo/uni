# Модели интеграции данных и приложений

Отчёты собираются в каталоге дисциплины командой `mise run report-all`. PDF появляются в
`reports/`. Для сборки одного отчёта достаточно Typst и шаблона `@local/pgups:0.1.0`.
Схема потока в первой работе использует пакет `@preview/cetz:0.5.2`.

```sh
mkdir -p reports
typst compile --root . lab-1/report.typ reports/lab-1.pdf
```

Таблицы расчётов лежат в `lab-*/results/`. Снимки и сохранённый проект выбора маршрута — в `lab-4/`.
Typst берёт листинги алгоритмов из файлов Julia как текст.
Julia нужна для пересчёта таблиц, консультаций в терминале и тестов.

| Работа | Расчёт |
| --- | --- |
| 1. Сборка фотокниг по сменам | `mise run solve 1` |
| 2. Маршрут школьного фотографа | `mise run solve 2` |
| 3. Экспертная система фотомастерской | `mise run expert` для консультации, `mise run solve 3` для обновления примеров |
| 4. Выбор способа проезда методом Саати | Открыть `lab-4/route.json` в Saaty AHP |
| 5. Оценка проектов по методу Николаева–Темнова | `mise run solve 5` |

`mise run test` запускает проверки четырёх программ. Используется Julia 1.13.4 и её стандартная библиотека.

Отдельный [обзор интерфейса и исходного кода Saaty AHP](saaty-ahp-review/report.typ)
собирается командой `mise run review` в `reports/saaty-ahp-review.pdf`. Иллюстрации и выдержки
из декомпилированных модулей входят в каталог обзора. Команда `report-all` собирает и обзор.
