# Реферат и презентация

Реферат «Автоматизация оформления учебных работ средствами Typst и пакета pgups»
по дисциплине «Интеллектуальные информационные системы и технологии».
Текст включает описание пакета, опыт подготовки ВКР, интеграцию Jupyter,
методику и результаты замеров времени сборки 190 документов.
Презентация содержит 12 слайдов, включая титульный. Текст выступления рассчитан
примерно на 6 минут 40 секунд с паузами и переключением слайдов.

Из корня дисциплины (на уровень выше):

```sh
mise run abstract      # reports/abstract.pdf
mise run presentation  # reports/presentation.pdf
mise run speaker-notes # reports/speaker-notes.pdf
mise run build         # все три документа
mise run fmt           # форматирование Typst
```

- `config.typ` — общие сведения, тема и необязательная дата презентации.
- `template.typ` — шаблон реферата: титульный лист и оформление из `@local/pgups:0.1.0`.
- `abstract.typ`, `chapters/` — точка входа и разделы реферата.
- `presentation.typ`, `presentation/` — презентация Touying с темой `university`,
  форматом 4:3 и логотипами, как в бакалаврской ВКР.
- `presentation/notes.typ` — общий текст заметок Touying и печатного выступления,
  привязанный к слайдам. Первая заметка содержит вступительную фразу о Typst и pgups.
- `speaker-notes.typ` — печатный текст с интервалами времени по слайдам и источниками
  для справки. Справочные строки не входят в выступление.
- `style.typ` — общие локальные настройки оформления.
- `bibliography.yaml` — 13 источников в формате Hayagriva; реферат использует
  библиографический стиль из pgups.
- `assets/build-times.svg` — готовый график распределения медиан времени сборки.
- `assets/notebook-before.svg`, `assets/notebook-after.svg` — реальные фрагменты
  PDF-экспорта Jupyter и отчёта Typst с одной таблицей. Векторный формат позволяет
  увеличивать их при показе. Происхождение описано в `assets/README.md`.
- `assets/markup-plots-before.svg`, `assets/markup-plots-after.svg` — текст и график
  из лабораторной № 4 до и после оформления в Typst, на отдельном слайде.

Каталог `benchmark/`, упомянутый в реферате и заметках к слайдам, перенесён
в `~/Projects/Repos/Probe/typst-build-benchmark/`. Там находятся скрипты и исходные
замеры в `runs/2026-11-17/`. Для повторного запуска скриптов нужна прежняя структура
каталогов: `run.py` определяет корень `uni` по своему пути, а `plot-abstract.py`
сохраняет график в `../assets/`.

Нужен установленный пакет `@local/pgups:0.1.0`; остальные Typst-пакеты загружаются
при первой сборке. Итоговые PDF сохраняются в `../reports/` и исключены из Git,
как и локальная памятка `findings.md`.
