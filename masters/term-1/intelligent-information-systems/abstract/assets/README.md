# Фрагменты для сравнения Jupyter и Typst

SVG с фрагментами получены из реальных PDF без перерисовки содержимого. Векторные фрагменты
сохраняют чёткость при увеличении презентации.

- `notebook-before.svg`: ячейки 12–13 (индексы с нуля) из `../../lab-3/lab.ipynb`.
  Они экспортированы через nbconvert в отдельный одностраничный PDF с сохранёнными
  результатами, без выполнения кода. В `notebook-export.tex.j2` заданы только шрифты
  с поддержкой кириллицы. Область фрагмента: `40 255 505 355` в PDF-пунктах.
- `notebook-after.svg`: страница 5 из `../../reports/lab-3.pdf`, собранного задачей
  `mise run report 3`. Область фрагмента: `85 120 470 150` в PDF-пунктах.
- `markup-plots-before.svg`: ячейки 4–5 из `../../lab-4/lab.ipynb`, экспортированные
  тем же способом. Показан фрагмент первой страницы с Markdown-заголовком, текстом,
  кодом и первым из четырёх сохранённых графиков. Область: `40 200 510 440`.
- `markup-plots-after.svg`: страница 3 из `../../reports/lab-4.pdf`, задача
  `mise run report 4`. Область: `85 325 470 425`.

Текст и код в SVG остаются векторными. Графики matplotlib сохраняют исходные
изображения из блокнота, их разрешение не изменено.

Для экспорта блокнота используется `jupyter nbconvert --to pdf` с параметром
`--template-file abstract/assets/notebook-export.tex.j2` из корня дисциплины.
PDF преобразованы командой `pdftocairo -svg`, затем в корневом элементе SVG
изменены только `viewBox`, `width` и `height`, чтобы убрать поля страницы.

## QR-код руководства

`pgups-docs-qr.svg` ведёт на `https://gitlab.pgups.ru/pages/typst/pgups/`.
Создан командой `qrencode -t SVG -m 4 -l Q -o pgups-docs-qr.svg 'https://gitlab.pgups.ru/pages/typst/pgups/'`.
Используются чёрные модули на белом фоне с защитным полем в четыре модуля.
